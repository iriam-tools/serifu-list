# わたしのセリフ帳

「罵倒」「甘々」各100件をベースに、自分用のセリフを編集・追加できる静的ウェブアプリです。原本の文章はそのまま取り込んでいます。

## 使えること

- 種類の切り替え、本文・番号の検索
- セリフの編集、連番での追加
- このブラウザへの自動保存
- 2種類をまとめてJSONに書き出し・読み込み
- 種類ごとに原本へ戻す（確認あり）

編集内容はサーバーに送信しません。同じ端末でもブラウザが変わると保存内容は別になります。ブラウザのデータ削除・プライベートブラウズの終了等で失われる場合があるため、必要な編集は書き出して保管してください。公開前のプレビューと公開URLも保存場所が別なので、移行には書き出し・読み込みを使います。

## 手元で開く

このフォルダで `python3 -m http.server 8937 --bind 127.0.0.1` を実行し、ブラウザで `http://127.0.0.1:8937` を開きます。ビルドや追加パッケージは不要です。

## GitHubへアップして公開する

1. GitHubにログインし、新しい公開リポジトリ `serifu-note` を作成します。
2. このフォルダの `index.html`、`style.css`、`app.js`、`base.js`、`README.md` をリポジトリの一番上にアップロードしてコミットします。ZIPのままアップロードせず、中身のファイルをアップロードしてください。
3. リポジトリの「Settings → Pages」を開きます。
4. Sourceを「Deploy from a branch」、Branchを「main」、フォルダを「/ (root)」にしてSaveします。
5. 公開処理が完了したら、Pages画面に表示されるURLを開きます。このURLを利用者に共有します。

公式手順：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## ファイル構成

- index.html：画面
- style.css：パソコン・スマホ用の見た目
- app.js：編集・保存・入出力
- base.js：2種類200件の原本

原本の更新はbase.jsを編集します。すでに各自が保存したセリフ帳は自動で上書きしません。「この種類を原本に戻す」で新しい原本を読み込めますが、その種類の個人編集は失われます。

## 検証済み

Chromeで原本表示、編集、追加、検索、再読み込み後の保存、種類切り替え、JSON書き出しと復元、不正JSONの拒否、利用者間の保存分離、390px幅で横にはみ出さないことを確認しました。
